StarHope 便携包升级

推荐方式（一步升级）：
1. 下载新版 StarHope-Portable.zip 和同名 .sha256，放进当前 StarHope 文件夹。
2. 双击原来的启动器：
   - Windows：StarHope.bat
   - macOS：StarHope.command
   - Linux：StarHope.sh
   启动器会先安全关闭本文件夹正在运行的题库，自动校验，把数据备份到 data_backup/upgrade-<时间>/，
   覆盖程序与 runtime，然后启动新版。升级完成后，新版 ZIP 会移到该备份目录中，不会重复升级。

如果无法自动确认并关闭该服务，升级会提示先在网页右上角点击电源按钮关闭，再双击启动器；不会覆盖任何文件。

升级只替换程序文件和 runtime，以下数据原地保留：
- starhope.db / starhope.db-wal / starhope.db-shm
- .env
- data_backup/
- static/uploads/
- .system_generated/

确认新版正常后，可以删除 data_backup/upgrade-* 下的旧备份与 applied.zip。

手动方式（备用）：
1. 关闭服务，复制整个旧文件夹做完整备份。
2. 解压新版到新目录，把旧目录中的上述数据路径复制到新目录；或保持原文件夹，只把新版程序文件与 runtime 覆盖进去，不要动数据路径。
3. 启动新目录。
4. 回退时先关闭服务，再换回旧文件夹或备份。不要用旧版程序打开已经由新版本迁移过的数据库。

Windows / macOS / Linux 便携包均内置对应平台的 Python 3.14.10 运行时，无需另行安装 Python。
